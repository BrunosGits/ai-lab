# Tags

Tag taxonomy for the AI Lab vault.

## Status Tags
- `#status/complete` — work is done
- `#status/in-progress` — actively worked on
- `#status/not-started` — planned, not begun
- `#status/blocked` — waiting on something external

## Domain Tags
- `#domain/infrastructure` — servers, firewall, docker, stack
- `#domain/learning` — roadmap studies (Transformers, Datasets, etc.)
- `#domain/ops` — runbooks, backup, rescue, journal
- `#domain/access` — services, credentials, Infisical paths

## Project Tags
- `#project/ai-lab` — the core project
- `#project/corsixth` · `#project/opensearch` · `#project/testcontainers` · `#project/expandir` — subprojects

## Phase Tags
- `#phase/0` · `#phase/1` · `#phase/2` · `#phase/3` · `#phase/4` — infrastructure phases
- `#month/1` · `#month/2` · `#month/3` · `#month/4` · `#month/5` — learning roadmap months
