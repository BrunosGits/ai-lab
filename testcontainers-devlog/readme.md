# 🧪 Testcontainers Contribution Lab

**Learning · Contributing · Publishing (GitHub + HF)**

A personal contribution laboratory for the Testcontainers ecosystem, hosted on the AI Lab VPS. Learning multi-language open source development (Java, Rust, Go, Python) by contributing real fixes to the Testcontainers project family. Each contribution gets published publicly as a portfolio.

## What's here

- `roadmap.md` — master plan: contribution phases, learning roadmap, repo matrix and sync strategy
- `testcontainers-vault/` — Obsidian vault with issue analysis, implementation logs, PR tracking, session journals
- `testcontainers-java/` — Fork of testcontainers/testcontainers-java (Java 21, Gradle)
- `testcontainers-rs/` — Fork of testcontainers/testcontainers-rs (Rust 1.85, Cargo)
- `scripts/` — Contribution helpers (sync forks, run tests, format checks)
- `assets/` — Testcontainers logo/icon

## Philosophy

- **VPS-first** — all builds, tests, and Docker run on the OVH VPS (4 GB RAM, 40 GB SSD)
- **Multi-language** — contribute across Java, Rust, Go, Python implementations
- **Testcontainers ecosystem** — focus on consistency, cross-language patterns, and developer experience
- **Publish everything** — code → GitHub forks + PRs, docs → Obsidian vault, demos → HF Spaces
- **Devlog as knowledge base** — every session logged, every decision traceable
