# Lua API and Object Implementation

## Overview

This document covers Lua coding conventions and how to implement custom objects, based on the wiki's Coding Conventions and Implementing Objects guides.

## 1. Coding Conventions

CorsixTH follows specific Lua coding conventions for consistency. Key points include naming, formatting, and structure for Lua files.

## 2. Implementing Objects

Objects are defined in `CorsixTH/Lua/objects/` with properties like `id`, `thob`, `name`, `tooltip`, `ticks`, and `orientations`. Each orientation defines `footprint`, `use_position`, `handyman_position`, and animations.
